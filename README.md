Hello, Welcome to SSS Coding Club! 

This is our github repository where we'll upload all our work. 
Github will make working and collaborating on different projects much easier, 
as well as being an excellent method to show off your work! 

To get started with 
collaboration, you have to clone the git repository to your computer. If you 
have git installed and set up on your computer:

    - Go to the main page of the repo 
    - Push the green "code" button 
    - Copy the code with the SSH encryption mode 
    - Type "git clone" into your terminal and paste the code from github 
    - Enter the command!
